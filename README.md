# 视觉运控通讯协议测试工具 - 使用说明

## 项目说明

这是一个完整的 Windows Forms 应用程序，用于测试视觉运控通讯协议的所有功能（T1-T8）。

## 最新优化

### UI 改进
✅ **优化控件间距** - 使用统一的布局常量，控件排列更整齐
✅ **下拉选择框** - 相机、吸嘴、模组等参数使用下拉选择，避免输入错误
✅ **提示信息** - 关键参数添加灰色提示文字
✅ **等宽字体** - 结果显示使用 Consolas 字体，数据对齐更清晰

### 参数配置

#### 相机选择（5个）
- 1 - 管壳上相机
- 2 - 管壳下相机
- 3 - 锗窗上相机
- 4 - 锗窗下相机
- 5 - 出料相机

#### 吸嘴/夹爪选择（4个）
- 1 - 吸嘴1
- 2 - 吸嘴2
- 3 - 吸嘴3
- 4 - 夹爪

#### 模组选择（3个）
- 1 - 管壳检测
- 2 - 锗窗检测
- 3 - 出料模组

#### 坐标输入（手动输入）
所有拍照位、取料位等坐标都可以手动输入，格式为 X,Y,R（逗号分隔）
- 示例：100.5,200.3,45.0
- 特殊值：999,999,999 表示不使用该参数

## 功能说明

### 连接管理
- **服务器IP**: 默认 127.0.0.1，可修改
- **端口**: 默认 7950，可修改
- **连接按钮**: 建立与视觉系统的TCP连接
- **断开按钮**: 断开当前连接
- **状态指示**: 红色=未连接，绿色=已连接

### 测试流程

#### T1 - 上下相机映射
- 用于上下相机的坐标映射标定
- 输入当前拍照位坐标 (X,Y,R)
- 返回对齐后的坐标

#### T2 - 九点标定
- 用于相机和机械坐标系的九点标定
- **相机下拉选择**：选择要标定的相机
- **模组下拉选择**：选择对应的模组
- **吸嘴/夹爪下拉选择**：选择使用的工具
- 步骤1: 清除标定点
- 步骤2: 执行9个点的标定（自动循环）
- 步骤3: 结束标定并保存

#### T3 - 吸嘴夹爪标定
- 标定吸嘴或夹爪中心与下相机图心的对齐
- **相机下拉选择**：默认选择管壳下相机
- **吸嘴/夹爪下拉选择**：选择要标定的工具
- 输入当前位置坐标
- 返回对齐坐标

#### T4 - 管壳模组上下相机对齐
- 管壳模组的上下相机对齐标定
- **相机下拉选择**：选择上相机或下相机
- 输入当前位置和吸嘴取位
- 提示：上相机拍照时，吸嘴取位填写 999,999,999

#### T5 - 管壳检测模组自动引导
- 管壳检测的取料和放料自动引导
- **相机下拉选择**：选择管壳相机
- **吸嘴下拉选择**：选择使用的吸嘴
- 输入拍照位1和拍照位2
- 提示：只拍一次时，拍照位2填写 999,999,999

#### T6 - 锗窗检测模组自动引导
- 锗窗检测的取料和放料自动引导
- **相机下拉选择**：默认选择锗窗上相机
- **吸嘴下拉选择**：支持吸嘴1/2/3和夹爪
- **取放料下拉选择**：1=取料，2=放料
- 输入拍照位1和拍照位2
- 提示：只拍一次时，拍照位2填写 999,999,999

#### T7 - 出料载具
- 出料载具定位和示教功能
- **功能下拉选择**：1=定位，2=示教
- 输入载具号（手动输入）
- 输入拍照位1、拍照位2和取料位
- 提示：定位功能时，取料位填写 999,999,999
- 定位功能返回所有穴位坐标

#### T8 - 出料载具穴位对齐图心
- 出料载具的三个Mark点对齐图心标定
- 输入载具号（手动输入）
- 输入三个拍照位置
- 返回三个Mark点的对齐坐标

### 日志功能
- 底部日志窗口实时显示所有通讯日志
- 黑底绿字的终端风格显示
- 时间戳精确到毫秒
- 清除日志按钮可清空日志内容

## 测试建议

1. **启动服务器**: 确保视觉系统服务器已启动并监听指定端口
2. **连接服务器**: 在程序中输入正确的IP和端口，点击连接
3. **选择流程**: 切换到要测试的流程标签页
4. **配置参数**: 
   - 使用下拉框选择相机、吸嘴、模组等参数
   - 手动输入坐标信息（格式：X,Y,R）
5. **发送测试**: 点击发送按钮执行测试
6. **查看结果**: 在标签页的结果区域和底部日志查看返回结果

## 注意事项

- 测试前必须先建立连接
- 所有坐标参数格式必须为 X,Y,R（用英文逗号分隔）
- 特殊值 999,999,999 表示该参数不使用
- 九点标定需要按顺序执行：清除 → 标定 → 结束
- 日志会记录所有操作和错误信息，便于问题排查
- 下拉框避免了输入错误，推荐使用
