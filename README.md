# 视觉运控通讯协议测试工具 v2.2

## 📋 项目简介

这是一个采用**三层架构设计**的 Windows Forms 应用程序，用于测试视觉运控通讯协议的所有功能（T1-T8）和 AOI 交互功能。

**特点：**
- ✅ 模块化设计，职责清晰
- ✅ 服务层独立，可直接集成到运控程序
- ✅ 配置集中管理，易于维护
- ✅ 科技感深色UI主题
- ✅ 支持配置自动保存和加载

## 💡 主要功能

### 1️⃣ 定位交互（T1-T8协议）

#### T1 - 上下相机映射
用于上下相机的坐标映射标定
- 输入当前拍照位坐标 (X,Y,R)
- 返回对齐后的坐标

#### T2 - 九点标定
用于相机和机械坐标系的九点标定
- 相机选择：5个相机选项
- 模组选择：3个模组选项
- 吸嘴/夹爪选择：4个选项
- 步骤：清除标定点 → 九点标定 → 结束标定

#### T3 - 吸嘴夹爪标定
标定吸嘴或夹爪中心与下相机图心的对齐
- 支持双拍照位一次性发送
- 返回对齐坐标

#### T4 - 管壳模组上下相机对齐
管壳模组的上下相机对齐标定
- 上相机/下相机分别标定
- 输入当前位置和吸嘴取位

#### T5 - 管壳检测模组自动引导
管壳检测的取料和放料自动引导
- 支持取料/放料功能
- 双拍照位支持

#### T6 - 锗窗检测模组自动引导
锗窗检测的取料和放料自动引导
- 支持取料/放料功能
- 双拍照位支持

#### T7 - 出料载具
出料载具定位和示教功能
- 定位功能：返回所有穴位坐标
- 示教功能：保存载具坐标

#### T8 - 出料载具穴位对齐图心
出料载具的三个Mark点对齐图心标定
- 三点拍照定位
- 返回对齐坐标

### 2️⃣ AOI交互

- **Capture命令**：普通拍照功能
- **Detect命令**：AOI检测功能
- **6个工位支持**：
  - GXFront - 管壳正面
  - GXBack - 管壳背面
  - ZCFront - 锗窗正面
  - ZCBack - 锗窗背面
  - Side - 侧面
  - Out - 出料俯拍

### 3️⃣ 连接管理

- **多端口支持**：同时管理4个端口（7920, 7930, 7940, 7950）
- **自动重连**：连接断开后自动尝试重连
- **状态显示**：实时显示连接状态（绿色=已连接，灰色=未连接）
- **端口选择**：每个Tab可独立选择使用哪个端口

### 4️⃣ 配置管理

- **自动保存**：端口选择、AOI服务器地址等配置自动保存
- **自动加载**：程序启动时自动恢复上次的配置
- **配置文件**：PortConfig.json（JSON格式）

### 5️⃣ 日志功能

- 终端风格显示（黑底绿字）
- 时间戳精确到毫秒
- 实时滚动显示
- 一键清除日志

## 🔧 集成到运控程序

### 使用服务层

服务层完全独立，可以直接在运控程序中使用：

```csharp
// 1. 创建协议服务
var protocolService = new ProtocolService();
protocolService.SetServerIP("127.0.0.1");

// 订阅日志事件
protocolService.OnLog += (msg, isError) => Console.WriteLine(msg);
protocolService.OnConnectionChanged += (port, isConnected) => 
    Console.WriteLine($"端口{port} {(isConnected ? "已连接" : "已断开")}");

// 2. 连接到端口
await protocolService.ConnectAsync(7950);

// 3. 获取协议实例并发送命令
var protocol = protocolService.GetProtocol(7950);
if (protocol != null)
{
    await protocol.SendT1Async("100.5,200.3,45.0");
    var response = await protocol.ReceiveT1Async(10000);
    Console.WriteLine($"结果: {response.X},{response.Y},{response.R}");
}

// 4. 断开连接
await protocolService.DisconnectAsync(7950);
```

### 使用AOI服务

```csharp
// 1. 创建AOI服务
var aoiService = new AOIService();
aoiService.OnLog += (msg, isError) => Console.WriteLine(msg);

// 2. 连接到AOI服务器
await aoiService.ConnectAsync("127.0.0.1", 8888);

// 3. 发送Capture命令
var response = await aoiService.SendCaptureAsync("GXFront", "0.123", "43.32");
Console.WriteLine($"图片路径: {response.Parameter1}");

// 4. 发送Detect命令
response = await aoiService.SendDetectAsync("GXFront", "0.123", "43.32");
Console.WriteLine($"检测结果: {response.Status}");

// 5. 断开连接
aoiService.Disconnect();
```

## 📝 使用说明

### 测试流程

1. **启动程序**：双击运行可执行文件
2. **自动连接**：程序启动时自动连接所有配置的端口
3. **选择功能**：
   - 点击顶部 Tab 选择"定位交互"或"AOI交互"
   - 在定位交互中选择 T1-T8 协议
4. **配置参数**：
   - 使用下拉框选择相机、吸嘴、模组等
   - 手动输入坐标（格式：X,Y,R）
5. **发送命令**：点击发送按钮执行
6. **查看结果**：在结果区域和日志区域查看返回信息

### 参数说明

#### 相机选择（5个）
- 1 - 管壳上相机
- 2 - 管壳下相机
- 3 - 锗窗上相机
- 4 - 锗窗下相机
- 5 - 出料相机

#### 吸嘴/夹爪选择（4个）
- 1 - 吸嘴1
- 2 - 吸嘴2
- 3 - 吸嘴3
- 4 - 夹爪

#### 模组选择（3个）
- 1 - 管壳检测
- 2 - 锗窗检测
- 3 - 出料模组

#### 坐标格式
- 标准格式：`X,Y,R`（用英文逗号分隔）
- 示例：`100.5,200.3,45.0`
- 特殊值：`999,999,999` 表示不使用该参数

### 注意事项

- ✅ 所有坐标必须用英文逗号分隔
- ✅ 特殊值 999,999,999 表示跳过该参数
- ✅ 九点标定需按顺序：清除 → 标定 → 结束
- ✅ 配置会自动保存，无需手动保存
- ✅ 日志记录所有操作，便于问题排查
